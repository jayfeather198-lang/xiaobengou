# 笨狗桌宠（圣诞节ver.）

一只会在 Windows 桌面上爬行、坐着、睡觉的小笨狗。
她自称「小小笨狗」，喊你「主人」，说话带「kiang」的口癖。

美术、动画、语音全部本地生成，不依赖任何在线服务。

![status](https://img.shields.io/badge/platform-Windows-lightgrey)
![python](https://img.shields.io/badge/python-3.11-blue)

## 下载即用

到 [Releases](../../releases) 下载最新的完整包（约 350 MB），解压后双击 **启动.bat**。
**不需要安装 Python 或任何依赖**，包内自带运行环境。

## 她会做什么

- 在桌面上四足爬行、坐下、趴着睡觉（大部分时间在睡）
- 点一下：喊痛，越点越生气，连点三下会被戳哭
- 双击：撸一撸（会闭眼蹭手）
- 拖拽：悬空摆动，松手落地
  - 高度不足半屏 → 空中翻个跟头轻落
  - 超过半屏 → 硬着地 + 摔落音效
- 拖到屏幕边缘 → 扒住边缘，上边缘单臂悬挂、左右侧身攀附（后腿会蹬）
- 空闲时会打哈欠、伸懒腰、突然盯着某处、追自己的尾巴
- 深夜（23:00–6:00）更容易困，会催你睡觉
- 你连续忙 35 分钟以上，她会转头看你，说「主人，歇一会儿吧」
- 睡着时会发生一些别的事……建议开「故事模式」+「沉睡模式」等她睡一会儿

右键菜单：喂苹果 / 撸 / 戳 / 捏脸 / 抱抱 / 挠痒痒 / 探头 / 摸摸项圈 / 戴上手套 / 睡觉 / 醒来 / 故事模式 / 幽灵梦境 / 沉睡模式 / 大小 / 退出

## 技术栈

| 环节 | 用的东西 |
|---|---|
| 界面 | PyQt6（桌面）/ PySide6（安卓移植中），无边框透明窗口 + 逐像素遮罩点击穿透 |
| 美术 | ChatGPT image2 生成 |
| 动画 | MiniMax H3 (Ref2VA) 本地生成，BiRefNet 抠像 |
| 语音 | IndexTTS 零样本克隆 |

## 从源码运行

```bash
pip install PyQt6
python src/main.py
```

需要素材目录（约 1 GB，可从 Release 包的 `assets/` 取得），放到 `src/` 同级或设置 `PET_ASSETS`。

## 自检

```bash
python tools/selfcheck.py    # 资源完整性 / 引用一致性 / 状态机 / 遮罩
python tools/selfcheck2.py   # 交互入口逐个调用
python tools/soak.py         # 55 秒随机压测
```

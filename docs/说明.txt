笨狗桌宠（圣诞节ver.）测试版 3.0
================================

【怎么运行】
  双击「启动.bat」。不需要安装 Python 或任何依赖。
  首次启动约 0.7 秒（素材改为按需加载）。

【3.0 修复】
  · 挠痒痒的手套不见了：内存优化重写加载列表时漏掉了该动画，程序自动退回旧版
  · 已补回，挠痒痒重新带手套

【2.9 修复】
  · 下落翻滚时人物被越翻越大：因为抠像时做了逐帧归一化，横躺帧被放大到统一高度
  · 改为全片统一缩放，翻滚全程大小一致

【2.8 修复】
  · 下落翻滚时遮罩没有跟随，导致画面被上一姿势的剪影裁掉
  · 现在遮罩逐帧跟随翻滚姿势（横躺时剪影变宽也正确跟随）

【2.7 改动：内存优化】
  · 动画帧不再开机全量载入，改为「用到哪一帧才解码哪一帧」
  · 全局最多缓存 110 帧（约 17 MB），超出后按最久未用淘汰
  · 实测内存：1021 MB → 约 290 MB（降 71%）
  · 启动时间：13 秒 → 0.7 秒
  · 切换状态不再有 0.3–0.5 秒的解码停顿

【2.6 及更早（本版包含）】
  · 轻巧落地：高度不足半屏时空中翻跟头 + 阻尼弹跳；超过半屏硬着地
  · 左右扒边时后腿在空中蹬踢挣扎；上边缘单臂悬挂
  · 手套手：撸一撸、捏脸（双手夹脸）、挠痒痒、抱抱
  · 环境感知：深夜催睡、连续忙 35 分钟关心一句、快速划过光标会被她盯住
  · 四条日常小动作：打哈欠 / 伸懒腰 / 突然盯着某处 / 追尾巴
  · 幽灵梦境、故事模式、沉睡模式、大小切换
  · 菜单平铺，互动项和「戴上手套」都在一级

【她会做什么】
  · 在桌面上四足爬行、坐下、趴着睡觉（大部分时间在睡）
  · 偶尔醒了会朝鼠标爬过来
  · 点一下：喊痛（越点越生气，连点三下会被戳哭）
  · 双击：撸一撸
  · 拖拽：拎起来会悬空摆动；松手后按高度决定硬着地还是空翻落地
  · 拖到屏幕边缘会扒住，扒一会儿会撑不住掉下去
  · 右键菜单：
      喂苹果 / 撸 / 戳 / 捏脸 / 抱抱 / 挠痒痒 / 探头 / 摸摸项圈 / 戴上手套
      睡觉 / 醒来
      故事模式 / 幽灵梦境 / 沉睡模式
      大小 / 退出

【故事模式】
  打开后她会说一句开场白，之后所有互动都换成另一套台词。
  台词只写当下的感受，不解释过去——细节需要玩家自己拼。

【隐藏内容】
  睡着时（尤其开着「幽灵梦境」）会发生一些事。
  建议开「故事模式」+「沉睡模式」，等她睡一会儿。

【已知问题】
  · 「戴上手套」不持久化，重启后需要重新勾选
  · 手套指针只在她身上生效，移到别的窗口会恢复普通箭头
  · 探头时窗口会缩到屏幕边缘，属于预期行为
  · 首次播放某段动画的第一个瞬间可能有一帧解码延迟（约 4ms，肉眼不可见）
  · 包内保留部分未使用素材（不会加载、不占内存）

【素材】
  美术：ChatGPT image2 生成
  动态：MiniMax H3 (Ref2VA) 本地生成 + BiRefNet 抠像
  配音：IndexTTS 零样本克隆 / 幽灵台词另用外部温柔音源
